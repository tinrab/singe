# Singe

A machine learning framework that sets tensors ablaze.

## Ecosystem

- [singe-cublas](./singe-cublas): Safe Rust wrappers for the NVIDIA cuBLAS dense linear algebra library (with cuBLASLt).
- [singe-cuda](./singe-cuda): Safe Rust wrappers for CUDA driver, runtime, NVRTC, NVVM, NVTX, memory, streams, modules, and graphs.
- [singe-cuda-macros](./singe-cuda-macros): Procedural macros for working with CUDA.
- [singe-cuda-find](./singe-cuda-find): CUDA toolkit discovery and library path resolution utilities.
- [singe-cufile](./singe-cufile): Safe Rust wrappers for NVIDIA cuFile GPUDirect Storage library.
- [singe-curand](./singe-curand): Safe cuRAND host API wrappers for CUDA random number generation.
- [singe-cudnn](./singe-cudnn): Safe Rust wrappers for the NVIDIA cuDNN deep neural network library. Includes backend and frontend APIs.
- [singe-cudss](./singe-cudss): Safe Rust wrappers for the NVIDIA Direct Sparse Solvers (cuDSS) library.
- [singe-cufft](./singe-cufft): Safe Rust wrappers for the NVIDIA cuFFT fast Fourier transform library.
- [singe-cusolver](./singe-cusolver): Safe Rust wrappers for the NVIDIA cuSOLVER dense and sparse solver library.
- [singe-cupti](./singe-cupti): Safe Rust wrappers for NVIDIA CUPTI profiling and callback APIs.
- [singe-cusparse](./singe-cusparse): Safe Rust wrappers for the NVIDIA cuSPARSE sparse linear algebra library.
- [singe-cutensor](./singe-cutensor): Safe Rust wrappers for NVIDIA cuTENSOR library.
- [singe-nvml](./singe-nvml): Safe Rust wrappers for NVIDIA Management Library (NVML), monitoring, MIG, and vGPU APIs.
- [singe-nccl](./singe-nccl): Safe Rust wrappers for the NVIDIA Collective Communications Library (NCCL).
- [singe-npp](./singe-npp): Safe Rust wrappers for NVIDIA Performance Primitives library (NPP).
- [singe-onnx](./singe-onnx): ONNX model loading utilities.
- [singe-ptx](./singe-ptx): CUDA PTX parser, AST, and instruction metadata utilities.
